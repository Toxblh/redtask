# RedTask — Support

RedTask is a native iPhone and iPad client for [Redmine](https://www.redmine.org) servers.

## Getting started
1. Enter your Redmine server address, for example `https://redmine.example.com`.
2. Enter your API key. In Redmine, open **My account** and find **API access key** → **Show**. If you don't see it, ask your administrator to enable the REST API (Administration → Settings → API).
3. To look around without a server, tap **Try Demo** on the sign-in screen.

## Known limitations
- New-activity notifications are checked on the schedule iOS allows, usually no more often than every 15 minutes. Redmine has no push notifications without a server plugin.
- Some servers only allow administrators to manage watchers through the API. In that case the app opens the web page instead.

# RedTask — Поддержка

RedTask — нативный клиент [Redmine](https://www.redmine.org) для iPhone и iPad.

## Начало работы
1. Укажите адрес сервера Redmine, например `https://redmine.example.com`.
2. Укажите API-ключ. В Redmine откройте **Моя учётная запись** и найдите **Ключ доступа к API** → **Показать**. Если его нет, попросите администратора включить REST API (Администрирование → Настройки → API).
3. Чтобы посмотреть приложение без сервера, нажмите **Попробовать без сервера** на экране входа.

## Известные ограничения
- Новые события проверяются по расписанию iOS, обычно не чаще раза в 15 минут. Без серверного плагина push-уведомлений в Redmine нет.
- На части серверов управлять наблюдателями через API может только администратор. Тогда приложение открывает веб-страницу.
